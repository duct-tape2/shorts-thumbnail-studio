# 쇼츠 썸네일 스튜디오

> 최초 설치 때만 인터넷이 필요합니다. 실행 파일을 작은 조각으로 받아 SHA-256 검사 후 자동 설치합니다. 설치 후에는 인터넷 없이 사용할 수 있습니다. 중간에 끊기면 같은 BAT를 다시 실행하면 완료한 조각부터 이어갑니다. 완전 오프라인 설치는 Release의 runtime-v1.2.0.zip.001~009를 설치 폴더의 downloads/에 모두 넣고 시작.bat을 실행하세요.

**사진과 문구를 넣고, 원하는 디자인을 설명하면 PNG를 만드는 Windows 프로그램입니다.**

인터넷 연결·로그인·API 키 없이 실행합니다. PhotoCraft가 이미지와 글자를 배치하며, 설명은 내장된 디자인 규칙으로 해석합니다. 생성형 AI나 새로운 사진 생성 기능은 사용하지 않습니다.

## 다운로드와 실행

1. 이 저장소의 **Releases → 최신 버전**에서 `ShortsThumbnailStudio-Setup-v1.2.0.zip`을 받습니다.
2. ZIP 전체를 쓰기 가능한 폴더에 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요.
3. `ThumbnailStudioSetup/시작.bat`을 실행합니다.
4. **디자인 설명으로 만들기**에서 큰 제목과 원하는 디자인을 입력하고 **썸네일 만들기**를 누릅니다.
5. 완성본은 `완성본/YYMMDD/큰 제목.png`에 저장됩니다. **저장 폴더 열기**로 확인하세요.

Windows 10/11 x64 대상입니다. Python, Photoshop 또는 PhotoCraft를 따로 설치할 필요가 없습니다. 공개판에는 회사 PSD·로고·실제 업무 캡처·작업 이력이 포함되지 않습니다.

## 디자인 설명 예시

| 설명 | 적용되는 설정 |
| --- | --- |
| `어두운 배경, 노란 포인트, 강렬한 느낌. 제목은 아래 가운데 정렬.` | 어두운 배경, 노란 강조색, 강렬한 타이틀 스타일, 하단 제목, 중앙 정렬 |
| `밝은 배경, 주황 포인트, 깔끔한 정보형` | 밝은 배경과 주황 강조색 |
| `차분한 매거진, 민트 포인트` | 매거진 스타일과 민트 강조색 |
| `사진 가득, 영화 같은 느낌. 제목은 아래에.` | 추가한 사진을 전체 배경으로 사용하고 하단 제목 배치 |
| `배경 #142B46 포인트 #FFD447` | 지정한 HEX 색상 적용 |

**큰 제목은 별도 입력란에 적습니다.** 디자인 설명에서 제목을 자동으로 추측하지 않습니다.
강조할 말은 제목에 실제로 포함된 문구를 입력하세요. 보조 문구와 출처/채널명은 선택 사항입니다.

## 제공 기능

- 6가지 기본 스타일: 정보형, 강렬한 타이틀, 매거진, 테크, 따뜻한 일상, 사진 중심.
- 쇼츠 1080×1920, 정사각형 1080×1080, 가로 1280×720 출력.
- 사진 파일 추가·드래그 앤 드롭·화면 영역 캡처.
- 사진이 없으면 텍스트와 도형으로 구성. 사진을 임의로 생성하지 않습니다.
- 제목 길이에 맞춘 줄바꿈과 글자 크기 조절, 출력 범위 검사.
- 날짜별 폴더, 제목 기반 파일명, 동명 파일 덮어쓰기 방지.
- 글자 인식 모델과 폰트 등 필요한 실행 파일은 휴대용 ZIP에 포함.

## 오프라인 설명 해석의 범위

스타일, 배경색, 강조색, 제목 위치, 정렬, 사진 배치를 준비된 규칙으로 조합합니다.
예를 들어 “우주에서 춤추는 고양이를 그려줘” 같은 새로운 장면 생성이나 모든 자연어 표현을 이해하지는 못합니다.
알아들을 수 없는 세부 요구는 반영되지 않을 수 있으니 미리보기를 확인하세요. 스타일 선택 메뉴로 원하는 스타일을 직접 지정할 수도 있습니다.

## 화면 캡처

- **화면에서 사진 캡처** 버튼 또는 Win+Shift+S로 범위를 선택합니다.
- Esc는 취소합니다. 캡처 원본은 앱의 `캡처/` 폴더에 저장되고 클립보드에 복사됩니다.
- 기존 CustomCapture 앱이 실행 중이면 단축키를 가져오지 않습니다. 새 앱의 캡처 버튼을 사용하세요.
- 창의 X는 트레이로 숨깁니다. 완전히 종료하려면 트레이 아이콘 우클릭 → **종료**.

## 저장 위치와 파일

- **저장 위치** 버튼에서 PNG 저장 폴더를 바꿀 수 있습니다.
- `assets/`, `vendor/`, `_internal/`은 실행에 필요하므로 앱과 함께 옮깁니다.
- `data/`에는 설정과 작업 보고서가 남습니다. 개인 사진 경로가 포함될 수 있으므로 공개 저장소에 올리지 마세요.
- 프로그램은 네트워크 전송을 하지 않습니다. 폰트는 첫 실행 때 현재 Windows 사용자에게 준비됩니다.

## 소스코드와 재빌드

같은 Release의 `Source-v1.2.0.zip`에는 전체 Python 소스, 공개 폰트, 라이선스, 테스트와 빌드 스크립트가 들어 있습니다.
실행용 ZIP에도 `소스코드/`가 포함되어 있습니다.

개발 환경은 Windows x64와 Python 3.12입니다. 소스 ZIP을 푼 폴더에서:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-lock.txt
.venv\Scripts\python scripts\bootstrap.py
.venv\Scripts\python -m unittest discover -s tests -v
.venv\Scripts\python main.py
.venv\Scripts\python build.py --public
```

`bootstrap.py`는 최초 개발 준비 시에만 PhotoCraft와 OCR 모델을 다운로드하고 SHA-256을 검사합니다. 완성된 휴대용 프로그램은 오프라인으로 실행됩니다.
빌드 결과는 `dist/ThumbnailStudio/`입니다. 공개판은 항상 `--public`으로 빌드해 회사 PSD가 포함되지 않게 하세요.

## 문제 해결

- **이미 실행 중**: 트레이에서 작업 창을 열거나 기존 프로그램을 종료한 뒤 다시 실행하세요.
- **문구가 길다는 메시지**: 제목 또는 보조 문구를 줄이세요. 잘린 결과를 억지로 저장하지 않습니다.
- **실행 오류**: `data/startup-error.log`를 확인하세요. 회사 보안 정책이 차단하면 담당 부서에 문의하세요.
- **그림이 예상과 다름**: 규칙 기반 기능이므로 설명을 예시처럼 구체적으로 쓰고 스타일 메뉴를 직접 선택하세요.
- **캡처가 흐림**: 원본 화면을 확대하고 더 큰 영역으로 캡처하세요.

## 검증 범위

15개 자동 테스트, 8가지 실제 PhotoCraft 출력(스타일·출력 비율·사진 배치), Qt 화면에서 설명 입력→PNG 생성, 창 크기 1280×850 및 1024×720을 검증했습니다.
공개판·비공개판 EXE는 각각 3회 시작 검사(Qt 창·OCR·글꼴·PhotoCraft)를 통과했습니다. 잘못된 CLI 입력도 팝업으로 멈추지 않고 오류 코드로 종료하는지 확인했습니다.
다른 물리적 PC 전체 환경을 검증한 것은 아닙니다.
